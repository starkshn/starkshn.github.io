위치, 회전, 스케일 제어

월드 행렬 / ImGui
ImGui를 통해 설정한 값을 월드 행렬(World Matrix)의 각 성분에 직접 대입하여 제어. 위치는 3행 성분, 회전은 회전 행렬을 Right/Up/Look에 곱셈, 스케일은 각 축 벡터에 스칼라 곱으로 구현.

위치는 enum값을 월드 행렬의 행 인덱스로 활용하여 vState 값을 대입합니다. 회전은 직교 좌표계를 만들고 특정 회전축(vAxis)으로 회전하는 행렬을 생성하여 Right/Up/Look에 대입합니다. 스케일은 각 축 벡터를 정규화(Normalize)한 뒤 매개변수 값을 곱하여 크기를 조절합니다.

FBX 뼈 인덱스화 및 관리

재귀 파싱 / XML 직렬화
Assimp으로 FBX를 로드하며 재귀적으로 뼈 데이터를 파싱, 각 뼈에 고유 인덱스를 부여. ImGui로 계층 구조를 시각화하고, 부위별 이름/인덱스를 XML로 저장·불러오기. 상하체 분리의 기반 시스템.

Model 클래스(전체 FBX 데이터), Bone 클래스(개별 뼈), Channel 클래스(애니메이션 채널)로 분리하여 관리합니다. 재귀적으로 읽으면서 동시에 인덱스 번호를 부여하여 효율적으로 접근할 수 있게 했습니다. 부위별 애니메이션 재생 시 인덱스 범위로 부위를 지정하여 해당 부위에 맞는 애니메이션을 선택할 수 있습니다.

애니매이션 제어

TrackBar / 루트 모션
TrackBar의 위치를 애니매이션 재생 시간 비율로 변환하여 역방향/순방향 탐색. 루트뼈 이동값을 제거하여 원점 재생(루트 모션) 구현. 행렬곱을 역으로 계산하여 되감기 효과 지원.

애니메이션 재생 시간에 따라 TrackBar 위치를 동기화하고, TrackBar를 드래그하면 위치를 총 재생시간 대비 비율로 변환하여 해당 시점의 행렬을 재구성합니다. 루트뼈의 이동값을 제거하면 애니메이션이 원점에서 재생되어 반복 확인이 용이합니다.

키프레임 이벤트

map 자료구조 / XML 직렬화
애니메이션 특정 프레임에 이벤트 데이터를 삽입하는 기능. map<string, map<string, vector<pair<string, float>>>>로 애니메이션→레이어→이벤트 계층 관리. XML 저장·불러오기로 영구 보존.

TrackBar와 동일한 좌표 변환을 적용하여 해당 위치에 동그라미 표시로 이벤트를 시각화합니다. std::map의 키 중복 불허 특성을 활용하여 이벤트를 효율적으로 추가·삭제합니다. 이벤트 위의 마우스 호버 시 툴팁으로 이름과 TrackPos를 표시하고, 우클릭으로 편집·삭제 메뉴를 제공합니다.

애니매이션 블렌딩

선형보간 / Quaternion Slerp
A 애니메이션 끝 키프레임에서 B 애니메이션 시작 키프레임까지 0.2초간 선형보간(Lerp/Slerp)하여 자연스러운 전환. Scale/Position은 XMVectorLerp, Rotation은 XMQuaternionSlerp로 구면 보간.

각 뼈의 Scale, Rotation, Position 값을 매 틱 추적하는 변수(Trace)를 유지하다가, 블렌딩 시작 시 현재 Trace 값(시작)에서 다음 애니메이션의 첫 키프레임(목적지)으로 보간합니다. 보간 비율은 경과 시간 / 보간 시간(0.2초)로 계산하며, 0~1로 클램핑합니다.

📝 키프레임 보간 — Trace 변수 추적 
// 매 틱 Scale/Rotation/Position 추적
m_vCurScaleTrace = vScale;
m_vCurRotationTrace = vRotation;
m_vCurPositionTrace = vPosition;

// 최종 변환 행렬: Affine Transformation
Bones[m_iBoneIndex]->Set_TransformationMatrix(
    XMMatrixAffineTransformation(
        XMLoadFloat3(&vScale),
        XMVectorSet(0.f, 0.f, 0.f, 1.f),
        XMLoadFloat4(&vRotation),
        XMVectorSetW(XMLoadFloat3(&vPosition), 1.f)));
📝 블렌딩 실행 — Lerp + Slerp 
void CChannel::Update_TransformationMatrix_Interpolation(...) {
    _float fRatio = fCurInterTrackPos / fInterTime;  // 보간 비율
    fRatio = min(max(0.f, fRatio), 1.f);              // 0~1 클램핑

    // Scale, Position: 선형 보간
    XMStoreFloat3(&vScale, XMVectorLerp(XMLoadFloat3(&vS0), XMLoadFloat3(&vS1), fRatio));
    // Rotation: 구면 보간 (쿼터니언)
    XMStoreFloat4(&vRotation, XMQuaternionSlerp(XMLoadFloat4(&vR0), XMLoadFloat4(&vR1), fRatio));
    XMStoreFloat3(&vPosition, XMVectorLerp(XMLoadFloat3(&vP0), XMLoadFloat3(&vP1), fRatio));
}

상하체 분리

뼈 인덱스 범위 / 부분 블렌딩
뼈 인덱스를 부위별 범위로 분할하여 상체/하체/양팔/머리에 각각 다른 애니메이션을 동시 재생. 부위간 전환 시 부분 블렌딩을 적용하여 자연스럽게 합성.

전체 200개 뼈를 인덱스 범위로 분할합니다 — 상체(4~150), 하체(151~194), 왼팔(6~39), 오른팔(40~73), 머리(75~148). XML에 BlendBone으로 각 부위의 시작 인덱스와 타입을 저장하고, 애니메이션 재생 시 자신의 부위 범위 내에서만 행렬 연산을 수행합니다. 전신 전환 시에는 변경이 필요한 부위만 부분 블렌딩을 수행합니다.

모델 뼈 확인

DXCollision 큐브 / DebugRay
XML 뼈 계층에서 특정 뼈를 선택하면 DXCollision 큐브가 해당 뼈 위치에 렌더링. DebugRay 객체로 뼈의 로컬/월드 Look 벡터를 시각화하여 방향 확인.

뼈의 Combined Matrix(루트까지 누적)에 오브젝트의 월드 행렬을 곱하여 월드 공간 좌표를 계산합니다. 여러 뼈를 동시에 표시할 때는 std::map으로 큐브 객체를 관리합니다. DebugRay는 뼈의 로컬 행렬 Look 벡터와 월드 변환 Look 벡터를 각각 표시하여, 로컬/월드 방향의 차이를 직관적으로 확인할 수 있습니다.

📝 뼈 월드 위치 계산 
_bool CLevel_AnimTool::Show_BoneWorldPos() {
    for (_int i = 0; i < m_SelectedShowBonesNames.size(); ++i) {
        // 루트 뼈까지 곱해진 특정 뼈의 행렬
        _matrix matBone = m_pAT_PartAnimObj_Model
            ->Get_Bone_CombiendTransformationMatrix(m_SelectedShowBonesNames[i]);
        // 오브젝트 월드 행렬과 곱 → 월드 좌표
        _matrix matWorld = matBone * m_pAT_Obj->Get_Transform()->Get_WorldMatrix();
        _vector vPos = matWorld.r[3];
        // 큐브 객체 위치 갱신
        pSquare->Get_Transform()->Set_State(CTransform::STATE_POSITION, vPos);
    }
}

특정 뼈 회전 (IK)

좌표계 변환 / 쿼터니언
타겟(마우스 월드 위치) 방향으로 특정 뼈(목/몸통)를 회전. 애니메이션 업데이트에서 해당 뼈를 제외한 뒤, 타겟과 뼈 위치를 루트뼈 좌표계로 통일하여 회전행렬을 계산, 다시 로컬 좌표계로 역변환.

핵심은 좌표계 통일입니다. 타겟의 월드 위치를 오브젝트 월드 역행렬 × 부모 뼈 Combined 행렬로 변환하여 루트뼈 기준 좌표를 구하고, 뼈의 Look 벡터도 동일 좌표계로 변환합니다. 두 방향 벡터의 내적(각도)과 외적(회전축)으로 쿼터니언 회전행렬을 생성한 뒤, BoneParentCombinedInv × RotMatrix × BoneParentCombined으로 로컬 좌표계 기준 회전행렬로 변환하여 적용합니다. Gimbal Lock 방지를 위해 외적 결과의 크기가 0에 가까우면 대체 축을 사용합니다.

📝 뼈 회전 핵심 코드 
void CModel::Rotate_UpdateExcludeBone_To_Target(
    string strBoneName, _fmatrix ObjWorld, _fmatrix TargetWorld)
{
    _matrix SrcMatrixInv = XMMatrixInverse(nullptr, ObjWorld);
    _matrix BoneParentCombined = Get_Parent_CombinedTransformationMatrix();
    _matrix BoneParentCombinedInv = XMMatrixInverse(nullptr, BoneParentCombined);

    // 타겟 → 루트뼈 좌표계로 변환
    _matrix NewTargetMatrix = TargetWorld * SrcMatrixInv * BoneParentCombined;
    _vector NewTargetPos = NewTargetMatrix.r[3];

    // 뼈 Look도 루트뼈 좌표계로
    _vector vBoneLook_Root = XMVector3TransformNormal(UEBLocalLookDir, BoneParentCombined);
    _vector vBoneToTarget_Root = XMVector3Normalize(NewTargetPos - vBonePos_Root);

    // 내적 → 각도, 외적 → 회전축
    _float fAngle = acosf(XMVectorGetX(XMVector3Dot(vBoneToTarget_Root, vBoneLook_Root)));
    _vector vRotAxis = XMVector3Normalize(XMVector3Cross(vBoneLook_Root, vBoneToTarget_Root));

    // 회전행렬을 로컬 좌표계로 역변환
    _matrix RotMatrix = XMMatrixRotationQuaternion(XMQuaternionRotationAxis(vRotAxis, fAngle));
    _matrix RotLocal = BoneParentCombinedInv * RotMatrix * BoneParentCombined;
    UEBLocalMatrix = UEBLocalMatrix * RotLocal;
}
