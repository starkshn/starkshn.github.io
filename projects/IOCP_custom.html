Thread Manager

TLS / Atomic
Thread Local Storage(TLS)로 스레드별 고유 ID 부여. Atomic 증가로 멀티스레드 안전. LockGuard(std::lock_guard)로 _threads 벡터 보호. Launch 함수에 std::function 매개변수.

Reader/Writer Lock

CAS / 스핀락 / 비트 플래그
_lockFlag 32비트 — 상위 16비트: Writer 소유자 TLS ID, 하위 16비트: Reader 공유 카운트. compare_exchange_strong(CAS)로 원자적 획득. 스핀락 + 타임아웃 크래시. RAII 패턴 ReadLockGuard/WriteLockGuard.

정책: W→W 재획득 가능, W→R 가능, R→W 불가

DeadLock Profiler

DFS / 사이클 탐지
락 획득 관계를 방향 그래프로 모델링. TLS std::stack에 방문 락 ID 기록 → _lockHistory에 간선 추가 → DFS로 사이클 탐지 시 즉시 크래시. _DEBUG 전처리문으로 릴리즈 무비용.

Protobuf + Jinja2 자동화

CMake / 배치 / pyinstaller
Google Protobuf를 CMake로 Debug/Release 빌드. .proto 파일(Enum/Struct/Protocol) 분리 관리. Jinja2 템플릿으로 PacketHandler.h 자동 생성 → pyinstaller로 exe 변환. 빌드 이벤트에 배치파일 등록하여 .proto 변경 감지 → 자동 빌드 + 코드 생성 + 복사 원클릭 파이프라인.
