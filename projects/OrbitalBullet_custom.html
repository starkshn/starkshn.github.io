플레이어 이동 및 상태 제어

비트 연산 / 부모 좌표계
비트 연산(OR/AND/NOT)으로 중첩 상태 관리 — 이동+점프+대쉬 동시 판정. 원형 스테이지의 중심점을 부모 행렬로 설정하여 행렬 연산으로 회전 이동.

게임이 중심점을 기준으로 원형 궤도를 도는 형태이므로, 플레이어의 부모 행렬을 스테이지 중심으로 설정하고 행렬 연산을 수행했습니다. 상태가 많아 enum 값만으로는 예외 처리가 복잡해지는 문제가 있어, 비트 연산으로 여러 상태를 동시에 관리하도록 전환했습니다. 대쉬 시에는 최대 회전값만큼 회전할 수 있게 하고, 점프 시에는 포물선 방정식을 활용하여 안쪽/바깥쪽 점프를 구현했습니다.

비트 상태 관리 핵심 
// 상태 추가 (OR)
void Add_State(STATE eState) {
    m_dwState |= (DWORD)eState;
}
// 상태 제거 (AND + NOT)
void Sub_State(STATE eState) {
    m_dwState &= ~(DWORD)eState;
}
// 상태 체크 (AND)
bool Check_State(STATE eState) {
    return (m_dwState & (DWORD)eState) != 0;
}

// 사용 예시: 이동+점프 동시 판정
if (Check_State(STATE::MOVE) && Check_State(STATE::JUMP)) {
    // 공중 이동 처리
}

카메라 이동 및 쉐이킹

선형보간 / 랜덤 쉐이킹
안쪽/바깥쪽 이동 시 반지름을 선형보간(Lerp)하여 줌인/줌아웃. 피격/보스 입장 시 카메라 At 좌표를 랜덤 미세 변경하여 쉐이킹 효과.

플레이어가 안쪽/바깥쪽으로 이동할 때 스테이지 중심점으로부터의 반지름 길이 자체를 선형보간하여 줄이거나 늘려, 부드러운 줌인/줌아웃 효과를 구현했습니다. 카메라 쉐이킹은 At 위치의 x, y값을 미세한 랜덤값으로 매 틱 변경하여 덜덜 떨리는 효과를 만들었습니다. 플레이어 피격과 보스 스테이지 입장 시 활성화됩니다.

Linear_InterPolation + Cam_Shake 핵심 
// 선형보간 — 반지름 기반 줌
void Linear_InterPolation(float fTargetRadius) {
    float fCurRadius = Get_Radius();
    float fLerp = fCurRadius + (fTargetRadius - fCurRadius) * m_fLerpSpeed * fDeltaTime;
    Set_Radius(fLerp);
}

// 카메라 쉐이킹
void Cam_Shake(float fIntensity, float fDuration) {
    if (m_fShakeTimer > 0.f) {
        float offsetX = (rand() % 100 / 100.f - 0.5f) * fIntensity;
        float offsetY = (rand() % 100 / 100.f - 0.5f) * fIntensity;
        m_vAt.x += offsetX;
        m_vAt.y += offsetY;
        m_fShakeTimer -= fDeltaTime;
    }
}
