카툰 쉐이딩

HLSL / Deferred Shading
깊이 버퍼 기반 외곽선 검출(DetectDepthEdges) + 법선 벡터 기반 보완(DetectNormalEdges)으로 섬세한 외곽선 표현. 스펙큘러 강도를 낮춰 만화 스타일 구현.

중심 픽셀과 상하좌우 4방향 주변 픽셀의 깊이값 차이를 누적하여 엣지 강도(EdgeStrength)를 구하고, saturate로 0~1 클램핑하여 최종 외곽선을 생성합니다. 깊이 변화가 작은 굴곡진 표면에서는 법선 벡터의 유클리드 거리를 기반으로 보완 검출합니다. 두 검출 결과를 조합하여 깊이 엣지가 0.9 이상이고 법선 엣지가 0.5 이상인 픽셀만 검은색 외곽선으로 렌더링하여, Deferred Shading 파이프라인의 후처리 단계에서 카툰 쉐이딩을 완성합니다.

📝 DetectDepthEdges 핵심 코드 
float DetectDepthEdges(float2 uv, float2 PixelSize) {
    float fViewZ = g_DepthTexture.Sample(LinearSampler, uv).y * 1000.f;
    float DepthOffsets[4];
    DepthOffsets[0] = g_DepthTexture.Sample(LinearSamplerClamp, uv + float2(-PixelSize.x, 0)).y * 1000.f;
    DepthOffsets[1] = g_DepthTexture.Sample(LinearSamplerClamp, uv + float2(PixelSize.x, 0)).y * 1000.f;
    DepthOffsets[2] = g_DepthTexture.Sample(LinearSamplerClamp, uv + float2(0, -PixelSize.y)).y * 1000.f;
    DepthOffsets[3] = g_DepthTexture.Sample(LinearSamplerClamp, uv + float2(0, PixelSize.y)).y * 1000.f;
    float fEdgeStrength = 0.0f;
    for (int i = 0; i < 4; ++i)
        fEdgeStrength += abs(fViewZ - DepthOffsets[i]);
    return saturate(fEdgeStrength * 15.f);
}

Glow (불꽃 이펙트)

Noise / Gaussian Blur / BillBoard
노이즈 텍스처로 UV 왜곡 → 이글거리는 불꽃 표현. 다운샘플링 → 가우시안 블러(X/Y축 분리) → 업샘플링으로 빛 번짐 효과. 빌보드 기법으로 카메라 방향 고정.

시간에 따라 Noise 텍스처의 UV를 변화시키고, 왜곡된 UV로 fire 텍스처에서 샘플링. lerp로 주황→노란 그라디언트 적용하여 자연스러운 불꽃 색상을 구현.

다운샘플링(해상도 1/2 축소)으로 연산량을 줄인 뒤 가우시안 블러 X축 → Y축 순으로 적용, 업샘플링하여 백버퍼에 합성. 저해상도에서 블러 처리하여 성능 최적화.

📝 Noise + Glow HLSL 
PS_OUT PS_MAIN_EFFECT_TORCH(PS_IN In) {
    PS_OUT Out = (PS_OUT)0;
    Out.vColor = g_Texture.Sample(LinearSampler, In.vTexcoord);
    if (Out.vColor.a < 0.1f) discard;
    float2 noiseUV = In.vTexcoord + float2(g_fNoiseCurTime * 0.5f, g_fNoiseCurTime * 0.7f);
    float2 noiseValue = g_TextureNoise.Sample(LinearSampler, noiseUV).rg;
    float2 distortedUV = In.vTexcoord + (noiseValue - 0.5f) * 0.05f;
    Out.vColor = g_Texture.Sample(LinearSampler, distortedUV);
    Out.vColor.a *= noiseValue.r;
    float3 gradient = lerp(float3(1,0.5,0), float3(1,1,0), noiseValue.r);
    Out.vColor.rgb *= gradient;
    return Out;
}

Rim Light (외곽선 강조)

Sobel Filter / 후처리
별도 렌더 타겟(TargetOuter)에 오브젝트를 초록색으로 렌더링 → 소벨 필터(Sobel Filter)로 경계 검출 → 빨간 외곽선만 추출. 깊이 테스트 무시로 벽 뒤 적 위치 표시 가능.

아래 두 이미지는 모두 완전 겉 테두리만 남기도록 만든 최종 결과 예시입니다. 별도 렌더 타겟의 ClearColor를 검은색으로 두고, 초록색으로 렌더링한 오브젝트에 소벨 필터를 적용해 검은색과 초록색이 만나는 정확한 경계면만 빨간색으로 추출했습니다.

📝 소벨 필터 HLSL 
PS_OUT_OUTER PS_MAIN_OUTER(PS_IN In) {
    PS_OUT_OUTER Out = (PS_OUT_OUTER)0;
    float4 vColor = g_OuterPreTexture.Sample(LinearSampler, In.vTexcoord);
    float2 UV = float2(1.0f/1280.0f, 1.0f/720.0f);
    float4 L = g_OuterPreTexture.Sample(LinearSampler, In.vTexcoord - float2(UV.x, 0));
    float4 R = g_OuterPreTexture.Sample(LinearSampler, In.vTexcoord + float2(UV.x, 0));
    float4 U = g_OuterPreTexture.Sample(LinearSampler, In.vTexcoord - float2(0, UV.y));
    float4 D = g_OuterPreTexture.Sample(LinearSampler, In.vTexcoord + float2(0, UV.y));
    float edge = sqrt(pow(abs(R.g-L.g),2) + pow(abs(D.g-U.g),2));
    if (vColor.g > 0.9f && edge > 0.1f)
        Out.vColor = float4(1,0,0,1);
    else discard;
    return Out;
}

Dissolve (소멸 이펙트)

Noise Texture / discard
노이즈 텍스처의 Alpha값과 시간 비율을 비교, 비율보다 작은 알파값은 discard하여 타들어가는 효과 연출. 보스 사망 시 사용. 경계면에 Burn Glow 색상을 추가하여 불타는 느낌 강화.

보스 몬스터가 쓰러진 뒤, 노이즈 텍스처(NoiseFire01.png)를 셰이더에 바인딩하고 디졸브 종료 시간까지의 비율을 매 틱 계산합니다. 현재 비율보다 노이즈 텍스처의 R값이 작으면 해당 픽셀을 폐기(discard)하고, 경계면에는 주황색 Burn Glow를 추가하여 불타는 느낌을 강화했습니다.

📝 Dissolve HLSL 
PS_OUT PS_MAIN_BOSS(PS_IN In) {
    PS_OUT Out = (PS_OUT)0;
    Out.vColor = g_DiffuseTexture.Sample(LinearSampler, In.vTexcoord);
    if (Out.vColor.a < 0.1f) discard;
    // Dissolve
    float noise = g_NoiseTexture.Sample(LinearSampler, In.vTexcoord).r;
    float dissolveRatio = g_fDissolveTime / g_fDissolveMaxTime;
    if (noise < dissolveRatio) discard;
    // 경계 번 효과
    if (noise < dissolveRatio + g_NoiseStrength) {
        Out.vColor.rgb += float3(1, 0.3, 0) * g_BurnGlowIntensity;
    }
    return Out;
}

BillBoard

카메라 방향 고정
횟불, 이펙트 등이 어느 위치에서 바라봐도 같은 모습을 보여주기 위해 항상 카메라를 바라보도록 빌보드(BillBoard) 기법 적용. 카메라의 Look 벡터 기준으로 Right/Up 벡터를 재계산하여 월드 행렬 갱신.

카메라의 뷰 행렬(View Matrix)을 역행렬하여 카메라의 Look 벡터를 추출하고, 이를 기준으로 오브젝트의 Right/Up 벡터를 외적(Cross Product)으로 재계산합니다. 매 프레임 월드 행렬을 갱신하여 항상 카메라를 정면으로 바라보도록 구현했습니다. 횟불뿐 아니라 모든 이펙트 클래스에서 공용으로 호출합니다.

📝 BillBoard 코드 
void CEffect::BillBoard() {
    _matrix ViewMatrix = m_pGameInst->GetTransformMatrix(CPipeLine::D3DTS_VIEW);
    _matrix ViewInverse = XMMatrixInverse(nullptr, ViewMatrix);
    _float3 vCamLook = XMVector3Normalize(ViewInverse.r[2]);
    _float3 vUp = _float3(0.f, 1.f, 0.f);
    _float3 vRight = XMVector3Normalize(XMVector3Cross(vUp, vCamLook));
    vUp = XMVector3Normalize(XMVector3Cross(vCamLook, vRight));
    m_pTransform->SetState(CTransform::STATE_RIGHT, vRight);
    m_pTransform->SetState(CTransform::STATE_UP, vUp);
    m_pTransform->SetState(CTransform::STATE_LOOK, vCamLook);
}

Trail Effect

버퍼 기반 / BillBoard
총알 궤적을 덱(Deque) 자료구조 기반 버퍼에 위치/시간 저장 → 일정 시간 후 자동 소멸. 빌보드 기법 적용.

TrailHigh/TrailLow 두 꼭짓점을 매 프레임 덱의 뒤(back)에 push하고, 수명이 다한 정점은 앞(front)에서 pop하여 자연스러운 궤적 소멸을 구현했습니다. 덱(Deque)을 사용한 이유는 트레일 정점이 생성 순서대로 소멸되어야 하면서도, 양쪽 끝에서 삽입/삭제가 O(1)로 가능하기 때문입니다. 일반 큐와 달리 필요 시 뒤에서도 제거할 수 있어 트레일 길이 제한이나 즉시 초기화에도 유연하게 대응 가능합니다.

빌보드를 적용하여 어느 방향에서든 궤적이 정면으로 보이도록 했습니다.

📝 Trail 정점 생성 코드 (CVIBufferTrail::AddVertices) 
void CVIBufferTrail::AddVertices(_fmatrix WorldMatrix, _float fTimeDelta)
{
    // 정점 수가 최대치를 넘으면 오래된 정점 2개(High/Low)를 pop_back
    if (m_iNumMaxVertices < m_TrailVertices.size() + 2)
    {
        m_TrailVertices.pop_back();
        m_TrailVertices.pop_back();
    }

    // 로컬 좌표계의 상/하 정점을 월드 좌표계로 변환
    _float fHighY = m_vLocalTrailHigh.y * m_fOffset;
    _float fLowY  = m_vLocalTrailLow.y * m_fOffset;
    _vector vLocalTrailHigh = XMVectorSet(m_vLocalTrailHigh.x, fHighY, m_vLocalTrailHigh.z, 1.f);
    _vector vLocalTrailLow  = XMVectorSet(m_vLocalTrailLow.x, fLowY, m_vLocalTrailLow.z, 1.f);

    VTX_POSTEX_TIME VtxTrailHigh = {}, VtxTrailLow = {};
    _vector vVtxTrailHighPos = XMVector3TransformCoord(vLocalTrailHigh, WorldMatrix);
    _vector vVtxTrailLowPos  = XMVector3TransformCoord(vLocalTrailLow, WorldMatrix);

    // LifeTime: x=최대수명, y=현재경과시간
    VtxTrailHigh.fLifeTime.x = m_fLifeTime;
    VtxTrailLow.fLifeTime.x  = m_fLifeTime;
    VtxTrailHigh.fLifeTime.y = 0.f;
    VtxTrailLow.fLifeTime.y  = 0.f;

    XMStoreFloat3(&VtxTrailHigh.vPosition, vVtxTrailHighPos);
    XMStoreFloat3(&VtxTrailLow.vPosition, vVtxTrailLowPos);

    // 새 정점을 deque 앞에 추가 (오래된 것은 뒤에서 제거)
    m_TrailVertices.push_front(VtxTrailHigh);
    m_TrailVertices.push_front(VtxTrailLow);

    m_iUsingCnt += 2;
    m_iUsingCnt = min(m_iUsingCnt, m_iNumMaxVertices);

    // Map/Unmap으로 GPU 버퍼 갱신
    D3D11_MAPPED_SUBRESOURCE SubResource{};
    m_pContext->Map(m_pVB, 0, D3D11_MAP_WRITE_NO_OVERWRITE, 0, &SubResource);
    VTX_POSTEX_TIME* pVertices = (VTX_POSTEX_TIME*)SubResource.pData;
    for (_uint i = 0; i < m_iUsingCnt; i += 2)
    {
        pVertices[i].vPosition     = m_TrailVertices[i].vPosition;
        pVertices[i + 1].vPosition = m_TrailVertices[i + 1].vPosition;
        pVertices[i].fLifeTime     = m_TrailVertices[i].fLifeTime;
        pVertices[i + 1].fLifeTime = m_TrailVertices[i + 1].fLifeTime;
        // UV 비율 계산
        float fRatio = float(i) / float(m_iUsingCnt);
        pVertices[i].vTexcoord     = { fRatio, 0.0f };
        pVertices[i + 1].vTexcoord = { fRatio, 1.0f };
    }
    m_pContext->Unmap(m_pVB, 0);

    m_iNumIndices = 3 * 2 * (m_iUsingCnt / 2 - 1);

    // 모든 정점의 경과 시간 갱신
    for (_int i = 0; i < m_iUsingCnt; ++i)
        m_TrailVertices[i].fLifeTime.y += fTimeDelta;
}

Particle & Instancing

Geometry Shader / GPU Instancing
Geometry Shader로 점(Point) → 사각형(Quad) 확장하여 파티클 생성, GPU Instancing으로 수백 개를 1 Draw Call로 렌더링. 파티클별 수명/속도/크기를 랜덤 설정하여 자연스러운 이펙트.

📝 파티클 역방향 수렴 (ReverseSpreadParticles) 
void CVIBufferParticleInstance::ReverseSpreadParticles(_float fTimeDelta)
{
    if (false == IsActivate()) return;

    D3D11_MAPPED_SUBRESOURCE SubResource{};
    m_pContext->Map(m_pVBInstance, 0, D3D11_MAP_WRITE_NO_OVERWRITE, 0, &SubResource);
    VTX_INSTANCE* pVertices = static_cast<VTX_INSTANCE*>(SubResource.pData);

    for (size_t i = 0; i < m_iNumInstances; i++)
    {
        // 현재 위치 → 중심(Pivot)으로 향하는 방향 계산
        _vector vDir = XMLoadFloat4(&pVertices[i].vTranslation)
                     - XMVectorSetW(XMLoadFloat3(&m_vPivot), 1.f);
        vDir = -vDir;  // 방향 반전 (바깥→안쪽 수렴)

        // 이동
        XMStoreFloat4(&pVertices[i].vTranslation,
            XMLoadFloat4(&pVertices[i].vTranslation)
            + XMVector3Normalize(vDir) * m_pSpeeds[i] * fTimeDelta);

        pVertices[i].vLifeTime.y += fTimeDelta;

        if (pVertices[i].vLifeTime.y >= pVertices[i].vLifeTime.x)
        {
            if (m_bIsLoopParticle) {
                // 루프: 초기 위치로 리셋
                pVertices[i].vTranslation = m_pInstanceVertices[i].vTranslation;
                pVertices[i].vLifeTime.y = 0.f;
            } else {
                pVertices[i].vLifeTime.y = pVertices[i].vLifeTime.x;
                if (AlmostEqual(pVertices[i].vLifeTime.y, m_fMaxLifeTime, 0.01f))
                    DeActivate();
            }
        }
    }
    m_pContext->Unmap(m_pVBInstance, 0);
}

Navigation Mesh

Pathfinding / Picking / 슬라이딩 벡터
마우스 Picking으로 삼각형을 직접 배치하여 NavMesh를 제작. 몬스터가 NavMesh 위에서만 이동하며 플레이어를 추적. 벽 충돌 시 슬라이딩 벡터를 적용하여 벽을 타고 자연스럽게 방향 전환.

레이캐스팅(Ray-Triangle Intersection)으로 마우스 클릭 위치에 삼각형 꼭짓점을 배치하여 NavMesh를 직접 제작합니다. 이동 시 현재 위치가 어떤 삼각형 위에 있는지 판별하고, 삼각형 밖으로 나가면 인접 삼각형으로 전환합니다. 벽(NavMesh 경계)에 충돌하면 이동 벡터를 벽의 법선에 투영하여 슬라이딩 벡터를 계산, 벽을 타고 자연스럽게 미끄러지도록 합니다.

Animation

KeyFrame / FBX / 블렌딩
FBX 모델에서 뼈대(Bone) 데이터를 로드하고 인덱스를 부여하여 관리. 키프레임 애니메이션 재생, 블렌딩(보간), 상하체 분리를 직접 구현.

Assimp 라이브러리로 FBX를 로드하여 계층적 뼈 구조를 파싱하고, 각 뼈에 고유 인덱스를 부여합니다. 애니메이션 재생 시 키프레임 간 보간(SQT: Scale/Quaternion/Translation)을 수행하며, 특정 뼈 인덱스를 기준으로 상체/하체를 분리하여 걷기(하체) + 공격(상체)을 동시 재생할 수 있도록 구현했습니다. 애니메이션 전환 시 블렌딩을 적용하여 끊김 없는 자연스러운 전환을 구현합니다.

UI 시스템

직교투영 / 원근투영 / 미니맵
직교투영으로 2D HUD(HP Bar, 스킬 아이콘), 원근투영으로 3D 월드 내 UI(데미지 폰트, 몬스터 HP Bar, 문 상호작용). 별도 렌더 타겟에 탑뷰 카메라로 그려서 미니맵 구현.

직교투영 UI는 스크린 좌표를 NDC 좌표계로 변환하여 뷰포트 중심 기준으로 배치합니다. 원근투영 UI(데미지 폰트, 몬스터 HP Bar)는 3D 월드 좌표에 그려져 거리에 따라 크기가 변하며, 카메라와의 거리가 멀수록 자연스럽게 작아집니다. 미니맵은 별도 렌더 타겟에 탑뷰 카메라로 씬을 렌더링한 뒤, HUD에 텍스처로 출력하는 방식입니다.

Player

FSM / State Machine
FSM(Finite State Machine) 기반 플레이어 상태 관리 (Idle/Walk/Run/Jump/Attack/Dash). 상태별 애니메이션 블렌딩 전환 + 총기 교체 시스템(1/2/3 슬롯).

키 입력에 따라 FSM 상태를 전환하고, 각 상태에 매핑된 애니메이션을 블렌딩하여 재생합니다. 총기는 1/2/3 슬롯으로 교체 가능하며, 총기별 발사 로직/이펙트/데미지가 다르게 적용됩니다. 이동 시 NavMesh 위에서만 이동하도록 제한하고, 점프/대쉬 시에는 충돌 판정을 별도로 처리합니다.

Monsters & Boss

FSM / AI / 다중 패턴
FSM 기반 몬스터 AI. 5종 일반 몬스터(각각 고유 공격 패턴) + 보스(점프내려찍기, 일반내려찍기, 메테오, 몬스터 소환, 컷씬 등 다중 패턴). NavMesh 기반 추적 + 구/AABB 충돌로 공격 범위 판정.

일반 몬스터는 Idle → Detect → Chase → Attack → Die 상태를 순환하며, 감지 범위 내 플레이어가 있으면 NavMesh 경로를 따라 추적합니다. 보스는 체력 구간별로 패턴이 변경되며, 컷씬 → 일반 공격 → 특수 패턴(메테오, 몬스터 소환) 순으로 전투가 진행됩니다. 모든 공격은 구(Sphere)/AABB 충돌 판정으로 데미지를 적용합니다.
