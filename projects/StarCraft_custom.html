A* 길찾기

우선순위 큐 / 휴리스틱
8방향 탐색에 우선순위 큐(PQNode)를 사용한 A* 구현. 휴리스틱(맨해튼 거리) + 직선 10/대각선 12 가중치로 최적 경로 탐색. std::stack으로 경로 역추적.

Obj 클래스에 A* 함수를 구현하여 모든 지상군 유닛이 공유합니다. best 이차원 배열을 INT32_MAX로 초기화한 뒤, 현재 화면에 렌더링되는 타일 범위(Min/Max Row/Col) 내에서만 탐색하여 연산량을 제한했습니다. 탐색 완료 후 parent 맵을 역추적하여 std::stack에 경로를 쌓고, 지나갈 타일을 노란색으로 표시합니다.

A* 핵심 코드 
// 우선순위 큐 + 8방향 탐색
priority_queue<PQNode, vector<PQNode>, greater<PQNode>> pq;
pq.push(PQNode{ start, 0 + Heuristic(start, dest) });
best[start.y][start.x] = 0;

while (!pq.empty()) {
    PQNode cur = pq.top(); pq.pop();
    for (int dir = 0; dir < 8; dir++) {
        int ny = cur.pos.y + dy[dir];
        int nx = cur.pos.x + dx[dir];
        int cost = (dir < 4) ? 10 : 12; // 직선 10, 대각 12
        int newG = best[cur.pos.y][cur.pos.x] + cost;
        if (newG < best[ny][nx]) {
            best[ny][nx] = newG;
            parent[ny][nx] = cur.pos;
            pq.push(PQNode{ {nx, ny}, newG + Heuristic({nx,ny}, dest) });
        }
    }
}
// stack으로 경로 역추적
stack<Pos> path;
Pos trace = dest;
while (trace != start) {
    path.push(trace);
    trace = parent[trace.y][trace.x];
}

차집합/교집합 유닛 선택

set_intersection / set_difference
드래그 영역 내 유닛을 수집 → 기존 선택과 std::set_intersection(교집합) → std::set_difference(차집합)으로 선택 해제 대상 추출. Possessed 플래그로 제어 가능 여부 관리.

마우스 드래그가 끝난 시점에 사각형 영역 안에 들어온 유닛 목록을 수집합니다. 기존 선택 유닛과 교집합(set_intersection)을 구한 뒤, 기존 유닛에서 교집합을 뺀 차집합(set_difference)이 선택 해제 대상입니다. 해제 대상의 Possessed 플래그를 false로 설정하여 제어에서 제외합니다.

교집합 + 차집합 핵심 
// 드래그 영역 내 유닛 수집
set<Unit*> newSelected;
for (auto& unit : allUnits) {
    if (IsInRect(dragRect, unit->GetPos()) && unit->IsPossessed())
        newSelected.insert(unit);
}
// 교집합: 유지할 유닛
vector<Unit*> keep;
set_intersection(prevSelected.begin(), prevSelected.end(),
                 newSelected.begin(), newSelected.end(),
                 back_inserter(keep));
// 차집합: 해제할 유닛
vector<Unit*> deselect;
set_difference(prevSelected.begin(), prevSelected.end(),
               newSelected.begin(), newSelected.end(),
               back_inserter(deselect));
for (auto* u : deselect) u->SetSelected(false);

마우스 상태 제어

더블클릭 / 드래그
'눌렀다-땠다'를 1동작으로 보고 특정 시간 내 재입력 시 더블클릭 판정. 누른 상태 유지 시 드래그 전환. 같은 종류 유닛만 더블클릭 선택.

마우스 좌클릭 '눌렀다→땠다'를 하나의 동작으로 보고, '땠다' 시점부터 시간을 누적합니다. 특정 시간 안에 다시 '눌렸다' 입력이 들어오면 더블클릭으로 판정하며, 이때 같은 종류의 유닛만 선택됩니다. '눌렸다' 상태에서 계속 누르고 있으면 드래그 상태로 전환하고, 드래그 텍스처와 사각형 영역을 렌더링합니다.

맵툴

타일 / 마우스 피킹
2차원 배열 기반 타일 배치 + 마우스 피킹으로 타일 타입 변경. 빨간색 = 이동 불가 영역. 나머지 연산으로 타입 순환.

맵 텍스처를 가져와 설정한 크기의 2차원 배열로 타일을 깔고, 마우스 피킹으로 선택한 타일의 타입을 변경합니다. 타입이 많지 않아 클릭할 때마다 값을 1씩 증가시키고 나머지 연산(%)으로 순환하도록 구현했습니다. 빨간색 타일은 A* 탐색에서 이동 불가 영역으로 처리됩니다.
