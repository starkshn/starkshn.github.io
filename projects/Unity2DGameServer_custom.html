접속 & 패킷 흐름

서버 권위 / 도식화
클라→서버 접속 후 Spawn/Despawn 패킷 교환. 서버 권위 기반 — 클라는 요청만, 서버가 검증 후 브로드캐스트. 전체 흐름을 3장의 도식으로 정리.

멀티플레이 테스트 툴

Unity Editor / 자동 빌드
Unity Editor MenuItem으로 2~4명 클라이언트 자동 빌드 & 실행. BuildPipeline.BuildPlayer + AutoRunPlayer 옵션. 일일이 빌드하는 번거로움 제거.
📝 PerformWin64Build 핵심 
[MenuItem("Tools/Build Multi Client")]
static void PerformWin64Build() {
    var scenes = EditorBuildSettings.scenes
        .Where(s => s.enabled).Select(s => s.path).ToArray();
    BuildPipeline.BuildPlayer(scenes, buildPath,
        BuildTarget.StandaloneWindows64,
        BuildOptions.AutoRunPlayer);
}

이동 동기화 & 스폰/디스폰

서버 권위 / 보간
클라가 PosInfo 패킷으로 좌표/방향/상태 전송 → 서버 검증 → 브로드캐스트. 피격 시 서버 좌표 기준 보간(interpolation). 스폰은 접속 시 서버가 생성, 디스폰은 연결 끊김 감지 → 패킷 전송 → 삭제.

투사체 동기화

Cell 기반 / 서버 권위
스킬 사용 패킷 → 서버가 투사체 생성 + 이동 + 충돌 판정. 클라는 서버 위치를 보간하여 렌더링만. Cell 기반 이동으로 빠른 투사체도 충돌 누락 방지.

데미지 & 죽음 판정

서버 권위 / S_ChangeHp
공격력/방어력/스킬 계수를 서버에서 계산 → S_ChangeHp/S_Dead 패킷 전송. 클라는 HP UI/피격 애니메이션만 처리. 몬스터 사망 시 일정 시간 후 서버 자동 리스폰. 치트 가능성 완전 제거.

이모티콘 & 채팅

브로드캐스트 / ScrollView
이모티콘: 키입력 → 서버 브로드캐스트 → 모든 클라에 표시. 채팅: InputField → C_Chat 패킷 → 서버 → S_Chat 브로드캐스트 → ChatLog UI. ScrollView + TextMeshPro 자동 정렬.

몬스터 AI

FSM / 서버 Tick / A*
서버 5ms Tick 기반 FSM: Idle→Moving→Skill→Hit→Dead. 주변 플레이어 탐색 → A* 경로 탐색 → 추적 → 공격. SpawnPoint 데이터 기반 패트롤/리콜/리스폰. 클라는 서버 상태 수신 + 보간만.

데이터 관리 & 맵 자동화

JSON / ILoader / Tilemap
JSON 파일(Stat/Skill)을 DataManager가 로드 → ILoader 인터페이스로 Dictionary 자동 변환. 서버 재시작 없이 데이터 반영. Tilemap_Collision 팔레트로 이동 불가 영역 칠하기 → 텍스트 파일 자동 저장.

스킬 시스템

SRP / ScriptableObject / 콤보
관심사 분리: Player=입력/이동, SkillRunner=캐스팅/콤보 판정, SkillAsset(ScriptableObject)=메타데이터. lockTime/comboInputWindow 타임스탬프로 콤보 판정. 방향 변경 시 첫타 리셋.
